Sends the account's own make.fun username, "zilol", as a single word — one word, nothing else — for the One Word, One Username, One Reward bounty. The program checks the word against the entry rules, writes exactly that word to /output/entry.txt, and reads it back to prove the judge sees precisely what was sent.

## Run it

```sh
python3 main.py
```
